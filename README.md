# SIMPEN — Sistem Manajemen Penelitian Dosen

Frontend statis (HTML/CSS/JS vanilla) untuk GitHub Pages. Backend: Google Apps Script (REST API).

```
index.html
css/style.css
js/config.js   ← isi GAS_URL di sini
js/api.js
js/app.js
```

Selama `GAS_URL` belum diisi, aplikasi berjalan di **mode demo** (data contoh tersimpan di browser, kata sandi admin: `admin`).
Ikuti `PANDUAN-INSTALASI.md` untuk pemasangan lengkap.
